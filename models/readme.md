# Model Files

This directory contains the model binaries bundled with MedRittAI. All active inference is powered by Jeevansh models.

```text
jeevansh/skin_cancer.pth
jeevansh/pneumonia.pth
jeevansh/brain_tumour.pt
jeevansh/fracture.pt
```

Legacy models (RAD-DINO, Brain MRI, Lung CT, Kidney Ultrasound) have been removed.
